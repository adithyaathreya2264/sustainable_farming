# Pinned exactly, not with >= lower bounds.
#
# The inherited requirements.txt pinned `scikit-learn>=1.3.0` while its shipped
# pickles had actually been written under 1.8.0. Tree-ensemble pickles are
# brittle across minor versions, so a fresh install following that file could
# produce artifacts that fail to unpickle or silently warn. Every model here is
# retrained from source rather than loaded from an inherited pickle, which
# removes that hazard — but the pins stay exact so a rebuild months from now
# reproduces the numbers recorded in MODEL_RESULTS.md rather than new ones.
#
# Install into a --system-site-packages venv at the repo root, so torch and
# pandas come from the global install rather than being duplicated:
#
#   python -m venv .venv --system-site-packages
#   ./.venv/Scripts/python.exe -m pip install -r ml/requirements.txt
#   ./.venv/Scripts/python.exe -m pip install torchvision --index-url https://download.pytorch.org/whl/cpu
