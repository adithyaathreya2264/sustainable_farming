Detailed Onboarding Screen Inventory

Step 1: Personalization & Language
Q1: Select Language
UI ComponentLarge visual cards (English, ಕನ್ನದ, हिन्दी, స౲లుగు, मराठी, etc.).
System BehaviourImmediately sets the React Context i18n state so the remaining questions render in the chosen language.
Q2: Full Name
UI ComponentNative Text Input field (the only typing field in the flow).
System BehaviourStored as user.name for personalized dashboard greetings.
Step 2: Farm Scale & Preferred Units
Q3: Land Measurement Unit
UI ComponentBottom-sheet picker containing standard regional units (Acre, Hectare, Guntha, Bigha, Cents, Killa).
System BehaviourSaved as user.default_unit. All future form inputs (like field mapping and fertilizer logs) will auto-select this unit for display while converting to metric in the database.
Q4: Total Farm Size
UI ComponentNumeric keypad input.
System BehaviourConverts user.total_farm_size to hectares and saves to the database for instant filtering of government scheme eligibility (e.g., smallholder vs. large farm thresholds).
Step 3: Location & Infrastructure
Q5: Irrigation Source
UI ComponentVisual radio cards with icons (Rainfed / Monsoon, Borewell, Canal, Drip/Sprinkler).
System BehaviourFeeds the Python ML engine to evaluate drought vulnerability and flags eligibility for irrigation subsidies.
Q6: Location Selection (State & District)
UI ComponentTwo sequential dropdowns: State Dropdown — populated with all 28 States and 8 Union Territories in India. District Dropdown — starts disabled. Once a State is selected, FastAPI fetches the corresponding districts for that State and populates this dropdown.
System BehaviourSaved as user.state and user.district. Crucial for filtering state-specific government subsidies (e.g., state schemes vs. central schemes) and localized weather/soil alerts.

Schema & API Impact

This onboarding sequence updates our MySQL Schema and FastAPI Service Endpoints:

1. Updated users Table (MySQL)

CREATE TABLE users (
    id VARCHAR(36) PRIMARY KEY,
    phone_number VARCHAR(15) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    language_pref VARCHAR(10) DEFAULT 'en',
    default_unit VARCHAR(20) NOT NULL,
    total_area_hectares DECIMAL(10, 4) NOT NULL,
    irrigation_type ENUM('Rainfed', 'Borewell', 'Canal', 'DripSprinkler') NOT NULL,
    state VARCHAR(100) NOT NULL,
    district VARCHAR(100) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

2. Location Helper Endpoints (FastAPI)

To support the dynamic Q6 dropdowns without bundling a heavy JSON file into the React Native app binary:

GET/api/v1/locations/states
Returns a list of all Indian states/UTs.
GET/api/v1/locations/districts?state={state_name}
Returns the array of districts for the requested state.
Once the user taps "Complete Profile," all 6 data points are written to WatermelonDB locally and synced via FastAPI to MySQL. They arrive at the Home Dashboard, where the empty state displays: "Welcome, [Name]! Tap '+' below to map your first field."
