The Daily Operating Rhythm (Kanban Mechanics)

To succeed in 6 weeks, the team must operate with ruthless efficiency.

The Daily Sync — 15 Minutes, Morning
Agenda: What did we move to "Done" yesterday? What is blocking the Engineer today?
Rule: The Technical Assistant's primary job is to resolve any blocker the Engineer raises within 2 hours.
Kanban Board Columns
Backlog→ Design in Progress→ Design Approved→ Ready for Dev→ Dev in Progress→ Ready for QA (Assistant)→ Done
The "Zero Friction" Rule for Dev
The Engineer should never have to look up an API endpoint, create test user accounts, or write placeholder data. The Assistant prepares all of this in advance.

Strict Quality & Testing Protocol

Because this is an offline-first agricultural app, standard web testing is insufficient. The Technical Assistant must execute the following QA script for every major feature:

The "Tunnel" Test
Open the app, start filling out a form (e.g., logging a chemical spray), and turn on Airplane Mode halfway through. Submit the form. Verify the app does not crash and the data saves locally.
The "Reconnection" Test
Turn Airplane Mode off. Wait 10 seconds. Check the Cloud Database (Firebase/Supabase console) to verify the data arrived perfectly.
The Conflict Test
Edit a field name on Device A (offline). Edit the same field name on Device B (online). Bring Device A online. Ensure the system handles the timestamp resolution gracefully without corrupting the database.
